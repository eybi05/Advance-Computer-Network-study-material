# Advance-Computer-Network-study-material

Study material for **CCNA Switching, Routing and Wireless Essentials (SRWE) v7**, modules 1–16.

| Path | What it is |
|---|---|
| `SRWE_Module_1.pptx` … `SRWE_Module_16.pptx` | The course module slide decks (plus `SRWE_Module_11.pdf`). |
| `srwe-study-lab/` | A study app built from these decks: lessons with slide errata, interactive visuals, 676 quiz questions, 337 flashcards, command drills, practice exams, and 28 Cisco Packet Tracer labs that are checked from the output you paste back. |
| `teacher's lab/` | The Packet Tracer activities (`.pka`) the instructor shared. The study app shows each one under **Instructor's labs**. |
| `START-SRWE-STUDY-LAB.html` | Opens the study app. |

## Use the study app

Clone or download the repository and open `START-SRWE-STUDY-LAB.html` (or `srwe-study-lab/index.html`) in Chrome, Firefox or Edge. Nothing needs to be installed. Progress is saved in your browser.

The labs are built in your own Cisco Packet Tracer (8 or 9). See [`srwe-study-lab/README.md`](srwe-study-lab/README.md) for details and for the test suite.
